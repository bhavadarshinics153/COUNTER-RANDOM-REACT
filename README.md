# StateFlow – React State Management Dashboard

StateFlow is a responsive React application built to practice and demonstrate React fundamentals through two interactive features: a Counter and a Random Number Generator.

### Features
- **Counter:** Increment, Decrement, and Reset functionality.
- **Minimum Limit:** Prevents the counter from going below zero.
- **Random Number Generator:** Generates random numbers between 1 and 100.
- **Conditional Rendering:** Displays messages based on component state.
- **Reusable Components:** Built using modular React components.
- **Responsive UI:** Clean and user-friendly design across devices.

### Technologies Used
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks (`useState`)
- Vercel (Deployment)
